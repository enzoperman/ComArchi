# ComArchi

## Rotational Gear Transfer Function Problem

This repository contains a LaTeX document (`rotational_gear_transfer.tex`) that demonstrates the analysis of a rotational gear system with transfer function derivation.

### Contents

The document includes:
- Problem statement for a two-gear rotational system
- Simplified system diagram showing all components
- Complete mathematical derivation of the transfer function
- Final boxed result

### System Components

The system consists of:
- Input voltage (Vi)
- Motor with inertia J1 and damper D1
- First gear (N1=10 teeth)
- Second gear (N2=20 teeth)
- Load with inertia J2 and damper D2

### Compiling

To compile the LaTeX document:
```bash
pdflatex rotational_gear_transfer.tex
```

### Features

- Clear simplified diagram placed right after the "Solution:" line
- Maintains all original parameters and equations
- Proper mathematical formatting with numbered equations
- Final result presented in a boxed format
